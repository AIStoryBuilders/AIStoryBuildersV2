# V1 fixture story

`before/` is the fixture story from [Test-Data.md §1](../../../Docs/Test-Data.md). It is generated by
`FixtureFactory` and checked by `FixtureFileTests`: regenerate it with `ASB_REGENERATE_FIXTURES=1 dotnet test`.

## Golden output (`after-<operation>/`) — needs a person

The `after-<operation>/` folders hold what **V1** writes for each golden operation (Test-Data §3). An agent can't
produce them: they must come from the V1 app's UI. Until a folder exists, its test in `GoldenOperationTests` is
reported as skipped.

Back up `Documents\AIStoryBuilders` first. Use a machine where V1 runs with the **en-US** culture.

For each operation:

1. Copy `before/Forgetting Baldur/` into `Documents\AIStoryBuilders\`, and add the row from
   `before/AIStoryBuildersStories.csv` to that folder's `AIStoryBuildersStories.csv` (keep your other rows).
2. Start V1, open **Forgetting Baldur**, and do the steps below.
3. Close V1. Copy `Documents\AIStoryBuilders\Forgetting Baldur\` to `after-<operation>/Forgetting Baldur/`, and copy
   the story's row into `after-<operation>/AIStoryBuildersStories.csv`.
4. Delete the fixture story from V1 (or restore your backup) before the next operation.

| Folder | Steps in V1 |
|---|---|
| `after-add-paragraph` | Chapters tab → Chapter 1 → open Paragraph 2 → **Add** → **Yes** ("Add Section above this Section"). Close without typing. |
| `after-rename-character` | Characters tab → Freya → Edit → Name `Freyja` → Save → confirm the rename |
| `after-rename-timeline` | Timelines tab → Present Day → Edit → Name `Now` → Save → confirm |
| `after-delete-chapter` | Chapters tab → Chapter 1 → **Delete** → confirm |
