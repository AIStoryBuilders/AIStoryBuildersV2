# Using Chat

The chat answers from your pages and cites them as links. Try:

- "How do I install it?"
- "Which pages link to Welcome?"
- "Summarize everything tagged start."
- "Create a Roadmap page that lists three next steps."

The assistant never changes a page by itself. Each change it proposes appears as a card with a diff, and nothing is written until you click **Apply**.

See also [[Linking Pages]].
