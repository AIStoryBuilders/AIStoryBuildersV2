# Linking Pages

Link pages with double square brackets:

- `[[Welcome]]` links to a page by name: [[Welcome]].
- `[[Getting Started/Install]]` links by path: [[Getting Started/Install]].
- `[[Install#API key]]` links to a heading: [[Install#API key]].
- `[[Install|setup guide]]` shows different text: [[Install|setup guide]].

A link to a page that doesn't exist yet is **unresolved**. For example, [[Roadmap]] has no page. The Links panel lists it, and you can create it from there.

## Aliases and tags

Front-matter at the top of a page can set a `title`, `tags` and `aliases`. A link can use any alias, so [[Chat]] opens the *Using Chat* page.
